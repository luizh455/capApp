# Security Policy

## Supported versions

Security reports are welcome for the latest public CapApp release. Older alpha
builds may no longer receive fixes; please verify whether an issue also affects
the latest release before reporting it.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting form](https://github.com/luizh455/capApp/security/advisories/new).
If private reporting is unavailable, contact the repository owner using the
contact information on the [maintainer's GitHub profile](https://github.com/luizh455).

Include the affected version, a description of the impact, and steps to
reproduce the issue. Please do not disclose the report publicly until a fix or
coordinated disclosure has been agreed.

You can expect acknowledgment within seven days. The maintainer will work with
you to understand and address the report; because this is an early-stage
project, a specific remediation timeline cannot be guaranteed.
