# Assets Directory

Default resources, icons, configurations, and test capture patterns for CapApp.

The `images/` folder contains the startup splash artwork. `splash.svg` is the editable source and `splash.png` is the raster image loaded by the native Windows window at launch.

The `icons/` folder contains the application icon. `capapp.png` is the source image, and `capapp.ico` is embedded into the Windows executable and used for the native window icon.
