# Code of Conduct

## Our standard

Everyone participating in the CapApp project is expected to be welcoming,
respectful, and constructive. We want participation to be free of harassment,
personal attacks, discrimination, and unwelcome sexual attention.

Communicate with empathy, respect differing viewpoints, accept constructive
feedback, and focus criticism on ideas and work rather than people. Do not
publish another person's private information without their permission.

## Scope

This code of conduct applies in project issues, pull requests, discussions, and
other spaces where someone is representing the project.

## Enforcement

Project maintainers may edit or remove content, close contributions, or block
participants who violate this code. To report an incident, contact the
repository owner privately through the contact information on the
[maintainer's GitHub profile](https://github.com/luizh455). Please include
relevant links or details and avoid making a public report when it concerns
someone's safety or privacy.
